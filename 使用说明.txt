================================================================================
  TCMS × AI —— 使用说明（新电脑篇）
================================================================================

这是一个"列车控制软件智能测试平台 + AI 测试工程师 Agent"。
解压后按下面的步骤操作即可，**不需要你事先安装 Python**。


--------------------------------------------------------------------------------
一、最快路径（三步）
--------------------------------------------------------------------------------

  第 1 步  把压缩包解压到任意目录
           建议路径不要有空格，例如  D:\tcms-agent

  第 2 步  双击   start.bat
           · 第一次运行会自动下载 Python 与依赖，需要联网，约 3~5 分钟
           · 之后每次启动都是秒开
           · 浏览器会自动打开 http://127.0.0.1:8000

  第 3 步  关闭那个黑色命令行窗口即停止服务


--------------------------------------------------------------------------------
二、三个入口（都在根目录）
--------------------------------------------------------------------------------

  start.bat        启动 Web 界面（总览 / 资产 / 知识图谱 / 场景 / Agent / 故障动画）
  agent-demo.bat   让 AI 测试工程师现场跑一遍完整链路（约 1 分钟，全程离线）
  test.bat         自检与测试（环境自检 + 全量回归 + 静态检查 + 评测基线）


--------------------------------------------------------------------------------
三、这台机器上需要什么
--------------------------------------------------------------------------------

  必需：Windows + 联网（仅首次）
  不需要：Python、Node.js、任何 API key、任何数据库

  为什么不需要 Python：包内自带 uv（一个独立的包管理器），它会自动准备
  Python 3.11 与全部依赖。若你的电脑已装 uv，脚本会直接用它。

  为什么不需要 Node：前端构建产物（web/dist）已随包提供。

  为什么不需要 API key：Agent 默认走"离线规则臂"——它与真模型走
  同一张工作流图、同一套工具、同一套权限与审计，只是决策由确定性规则
  做出。配置 key 后可切换到真模型（见第五节）。


--------------------------------------------------------------------------------
四、常见问题
--------------------------------------------------------------------------------

  Q：双击后窗口一闪而过 / 提示找不到 powershell
  A：本包使用 Windows 自带的 PowerShell。若被安全软件拦截，
     右键 start.bat → 以管理员身份运行；或手动执行：
         powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1

  Q：提示"无法获得 uv"
  A：三种办法任选：
     ① 联网后重新双击（脚本会自动安装 uv）
     ② 手动装：powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
     ③ 从 https://github.com/astral-sh/uv/releases 下载 uv.exe，
        放进本目录的 _offline\ 子目录里

  Q：提示"依赖同步失败"
  A：多为网络或代理问题。若本机配了代理而代理未开，git/uv 会连不上：
         git config --global --unset http.proxy
         git config --global --unset https.proxy
     若拿到的是**含离线缓存的完整包**（包内有 _offline\uv-cache），
     可设环境变量 TCMS_OFFLINE=1 后重试，全程不联网：
         set TCMS_OFFLINE=1
         start.bat

  Q：8000 端口被占用
  A：换一个端口：
         set PORT=8001
         start.bat

  Q：路径有中文或空格，会出问题吗
  A：通常可以，但个别 Python 工具链对含空格路径敏感。
     若遇到莫名报错，换到 D:\tcms-agent 这类简单路径再试。

  Q：想确认"解压出来的这套东西是好的"
  A：双击 test.bat。它会跑：环境自检 → 1528 项全量回归 → 静态检查 →
     端到端评测基线（规则臂须达 10/11 且零幻觉引用）。
     全绿即表示本机环境完全正常。


--------------------------------------------------------------------------------
五、进阶用法（可选，不影响基本使用）
--------------------------------------------------------------------------------

  用真模型（需自备 key）：

      set DASH_API_KEY=sk-xxxx
      uv run tcms-agent run "验证车门故障必须触发降级处置" --llm

  命令行直接用 Agent（15 个工具、四级权限）：

      uv run tcms-agent tools          列出工具与权限级别
      uv run tcms-agent run "<目标>"    跑一个目标
      uv run tcms-agent history <id>   回放某次运行的轨迹（逐超级步）
      uv run tcms-agent memory stats   查看四层记忆
      uv run tcms-agent eval run       跑端到端评测
      uv run tcms-agent nolib --verify 框架版 vs 手写最小 loop 对照

  开放持久化写入（会要求你在终端逐项审批）：

      uv run tcms-agent run "<目标>" --allow-write


--------------------------------------------------------------------------------
六、这个包里有什么
--------------------------------------------------------------------------------

  start.bat / start.ps1            启动 Web 界面
  agent-demo.bat / .ps1            Agent 演示
  test.bat / test.ps1              自检与测试
  _tools\common.ps1                启动脚本共用的引导逻辑
  packages\engine\                 领域引擎与真实资产（原 tcms-can-test）
  packages\platform\               资产模型 + 知识底座 + Web（原 tcms-ai-platform）
  packages\testgen\                受约束生成与变异杀毒（原 tcms-ai-testgen）
  packages\agent\                  Agent：工作流 / 四级权限 / 四层记忆 / 评测
  docs\ARCHITECTURE.md             架构说明（现状，含全部实测数字）
  docs\decisions.md                18 条设计决策记录（含每条的代价与踩过的坑）
  README.md                        项目总览

  详细文档见 README.md 与 docs\ 目录。
  源码与完整 git 历史在 https://github.com/zych2002918/tcms-agent


--------------------------------------------------------------------------------
七、卸载
--------------------------------------------------------------------------------

  直接删除整个目录即可。若还想清掉缓存（uv 下载的 Python 与依赖）：

      删除  %LOCALAPPDATA%\uv
      删除  本目录下的 .venv

  以上都不影响系统其它软件。
